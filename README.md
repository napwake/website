# napwake.dev

The website for [Napwake](https://github.com/napwake/napwake), built with [Astro](https://astro.build).

```sh
npm ci
npm run dev     # a local preview
npm run build   # the site, in dist/
```

Every push to `main` deploys to GitHub Pages. Issues and changes to Napwake itself go to [napwake/napwake](https://github.com/napwake/napwake).
